# pc2img — modified branch for tls2dseg

This branch is a modified/personal development branch (development/tomislav) of an outdated copy of `pc2img`. It is used as a dependency for `tls2dseg`.

The main project README and stable documentation are maintained on the `main` branch. This branch may contain experimental changes, API deviations, or temporary modifications needed by `tls2dseg`.

Use this branch with caution unless you specifically need the `tls2dseg` integration.

## Differences from main

The diff is large because the `main` branch of `pc2img` has undergone substantial restructuring since this branch was created. I am not sure if I did any relevant changes to this branch after forking (hence, nothing is documented here).
