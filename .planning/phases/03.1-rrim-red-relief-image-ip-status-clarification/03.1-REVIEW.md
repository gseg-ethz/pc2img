## Warnings

### WR-01: `rrim.py` module docstring is dead — `from __future__` ordering makes it a bare expression

**File:** `src/pc2img/features/rrim.py:1-11`
**Issue:** The module opens with `from __future__ import annotations` on line 1,
followed by the triple-quoted string on lines 3-11. Because a module docstring
must be the *first* statement, the future-import statement demotes the string to
an ordinary (discarded) expression. Confirmed empirically:

```
ast.get_docstring(module) -> None
```

So `pc2img.features.rrim.__doc__` is `None`. The block that explains the
image-space/NumPy design intent is invisible to `help()`, Sphinx autodoc, and any
tooling that reads `__doc__`. In a phase whose entire deliverable is *reconciled,
accurate docstrings*, shipping a module docstring that introspection cannot see
undercuts the intent. (This originated in the file-creation commit `a2baa3e`, not
the docstring commit, but it lives in a file under review and defeats a documented
goal of this phase.)

**Fix:** Put the docstring first, then the future import (the only statements
permitted before a `from __future__` import are the docstring, comments, and blank
lines):

```python
"""
RRIM utilities and feature registrations.

The implementation is intentionally image-space and NumPy-only ...
"""

from __future__ import annotations

import re
...
```

### IN-01: PTA reasoning conflates "priority" with "filing" in the US-expiry rationale

**File:** `docs/ip/rrim-ip-findings.md:82-86`
**Issue:** The doc argues the 2025-10-05 adjusted expiration is "consistent with
the twenty-years-from-filing rule plus patent-term adjustment" applied to a
"2002-11-05 priority." Twenty years from a 2002-11-05 date is 2022-11-05; reaching
2025-10-05 implies either ~3 years of PTA or (more likely) that the 20-year clock
runs from a later US/PCT national-phase filing date, not the 2002 priority. The
prose slightly conflates priority date with filing date. The *conclusion*
(expired, since 2025-10-05 < today 2026-07-10) is unaffected — this is a
reasoning-precision nit, not a factual error, and the doc is explicitly labeled
good-faith and non-binding.
**Fix:** Reword to note the 20-year term runs from the US application/PCT filing
date (later than the 2002-11-05 priority), plus any PTA — or simply drop the
arithmetic justification and rely on the cited Google Patents "Expired - Lifetime"
status, which is the load-bearing fact.

### IN-02: Sign-off doc asserts CI/coverage state that this review cannot verify

**File:** `docs/ip/rrim-eth-signoff.md:62-68`
**Issue:** §3 states the frozen coverage-gated suite passes at `--cov-fail-under=35`
and that the legal docs are VCS-tracked and thus in the sdist. These are

confirmed the suite run; flagged only so the claim is not treated as
source-verified.
**Fix:** None required. Optionally cite the CI run/commit that produced the
green-at-35 result so the assertion is auditable.
