Purpose — three problems, each reproduced or verified against HEAD before this plan was written:

- **WR-02 (major, security).** `_get_npy_path(key)` / `_get_meta_path(key)` build `cache_dir / f"{key}.npy"`
  with no check that the result stays inside `cache_dir`, and 05-14 turned `__delitem__` into an
  unconditional `unlink`. Reproduced 2026-07-28 on HEAD: with a sentinel file one level above the cache
  directory, `add_image_to_store("../victim", arr)` + `offload_image_data_to_disk` **overwrote the sentinel
  with an NPY header**, and `del store["../victim"]` then **deleted it**. Not reachable from the feature-name
  DSL today — every registered `regex_pattern` anchors on a literal prefix, so no store key can begin with
  `..` or `/` — but `DiskBackedImageStore` is exported from the public barrel `pc2img.image_cache.__all__`,
  and this phase is what made `__delitem__` a file-deletion primitive.
- **WR-03 (major, BC record).** Widening `_Z_FACTOR_RE` moved names matching `z\d+(\.\d+)?[eE][+-]?\d+` out
  of the base-feature class and into the option class. Measured 2026-07-28: `_parse_rrim_config("z1e5")`
  yields `base_feature='range', z_factor=100000.0`; the pre-05-14 pattern rejects `z1e5`, so pre-diff the
  same name yielded `base_feature='z1e5', z_factor=1.0`. Same public name, same cache key, different
  computation. Feature names are both public API and cache key, so per CLAUDE.md this is a BC event.
  **Owner decision 2026-07-28: the new precedence is accepted as correct — BC-NOTES entry + pinning test,
  NO behaviour change.**
- **Stale bookkeeping.** `gsd-tools query audit-uat` currently reports **22 open items** for `05-UAT.md`,
  including four ROUND 2 entries that plan 05-14 demonstrably closed and eight 2026-07-11 entries the file's
  own comment records as closed by 05-13. GSD's `close_parent_artifacts` step only runs for decimal phases
  (e.g. `05.1`), so nothing flipped them and `/gsd-ship` still reads `failed`.

Output: one containment authority + proving tests, one comment correction + pinning tests, two BC-record
entries, and an evidence-cited reconciliation of the gap statuses. No behaviour change to the RRIM math, the
feature-name grammar, or the delete ordering.
