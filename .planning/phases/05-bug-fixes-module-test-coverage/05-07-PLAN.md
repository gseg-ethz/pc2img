<objective>
Unify the two divergent registries (D-14 / DSN-05): a single miss-exception type across
`StrategyRegistry` and `FeatureRegistry`, and a `dependencies_for(params)` classmethod so
`FeatureRegistry.match()` stops instantiating the feature class just to read `.dependencies`. Fold in
DSN-11 (`_default_cls: type[...] | None`). Cover the feature-name DSL (TEST-04). Test-first (D-12).

Purpose: The two registries have different miss exceptions (`KeyError` vs `RuntimeError`), lifecycles,
and a side-effectful double-construction in `match()`. Unify with a **dual-inheritance**
`class RegistryLookupError(KeyError, RuntimeError)` so every existing `except KeyError` AND
`except RuntimeError` caller keeps working — the unification breaks ZERO callers/tests (grep-confirmed:
no `pytest.raises(KeyError|RuntimeError)` in tests/). CRITICAL correction to the FINDINGS framing:
`FEATURES.match` on an UNKNOWN name does NOT raise — there is a `default=True` feature; unification
MUST preserve that default-fallback, not force a raise. The miss-exception TYPE change is a BC-01 entry.
Output: unified registries + `dependencies_for` + `tests/test_feature_registry.py`.
</objective>
