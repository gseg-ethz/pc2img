joblib loky errors: `joblib.externals.loky.process_executor.BrokenProcessPool` and `TerminatedWorkerError` are `RuntimeError` subclasses (via `concurrent.futures.process.BrokenProcessPool` -> `BrokenExecutor`). Two propagation paths exist and the race can take either: a worker killed by SIGBUS, or one whose call item fails to unpickle, surfaces in the parent as `TerminatedWorkerError` (RuntimeError); a worker that raises a Python exception inside the task body has THAT exception re-raised in the parent by joblib (`FileNotFoundError`, an `OSError`, for the `<key>.dat.tmp` chmod). Research measured `BrokenProcessPool` 3/3 at the pc2img level on a scratch overlay (07-RESEARCH.md "Surprise"); which type(s) the migrated tree produces is measured in Task 1, not assumed.
