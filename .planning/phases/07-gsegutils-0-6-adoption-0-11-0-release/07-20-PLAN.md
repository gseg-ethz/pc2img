<objective>
Close G2-WR-01 and G2-WR-04. The redirect the reviewer found is not confined to the soft branch, and a symlink check inside that branch does not close it: the write path opens temporary names, and the round-2 gate never consults them. Checker measurement on HEAD `c1b813d`: a planted `k.dat.tmp -> other.dat` makes `add_image_to_store("k", ...)` write the new raster into `other` in a forked non-owner child (exit 0) AND in the owner process; `k.dat -> other.dat` in a non-owner leaves `other` intact only because the `.dat` write is deferred (an entry-level `offload` later writes through it). 07-13's six-member gate caught this incidentally; 07-17's narrowing, which ignores temporary names, removed that protection. The fix is a pre-write refusal in pc2img: before the purge gate and before any write, in every process, if any of the paths the write opens for the key — `<key>.dat`, `<key>.dat.tmp`, `<key>.npy.tmp`, `<key>.meta.json.tmp` — is a symlink, raise the upstream class that names the shape (`StorePurgeAliasedArtefactError` for a link resolving inside the cache directory, `StorePurgeForeignArtefactError` for one resolving outside; both are `StorePurgeRefusedError`, so the method's documented `except` contract is unchanged). The `<key>.npy` / `<key>.meta.json` finals are deliberately not in this set: writes only `os.replace` onto them (the link itself is replaced, its target untouched) and a link there is the legitimate adopted-entry shape upstream's purge reconciliation handles. The round-2 soft-branch re-raise for a linked `.dat`/`.meta.json` leftover stays as a second layer (it is what keeps the `meta_link` non-owner case refused). Separately, the `popitem` drop-route case keeps the popped entry bound; `popitem()` reloads the key and rewrites `range.dat`, so the soft `.dat` leg catches the key and the case survives the c2 mutant — it never sensed the hard gate.

Purpose: a planted link inside the cache directory must not let any process overwrite another key's file silently; the drop-route tests must guard the member they were written for.
