  <action>
    Add three new tables to `pyproject.toml` (place them after the existing
    `[dependency-groups]`/`[tool.uv]` region; ordering is cosmetic but keep them grouped).

    `[tool.pytest.ini_options]` (satisfies TEST-01 config half, per D-01/§1):
    - `testpaths = ["tests"]` — the single load-bearing key. `third_party/` is a sibling
      of `tests/`, so this stops recursion into the gitignored sibling checkouts (verified:
      bare pytest 1140 collected / 7 errors → scoped 26 collected / 0 third_party errors).
    - `addopts = "--import-mode=importlib --strict-markers"` — modern import machinery
      (avoids duplicate-basename import-file-mismatch) + strict markers. Do NOT add any
      `--cov` flag here (see key constraint below).
    - `xfail_strict = false` — documents the default so an unexpected XPASS (when Phase 5
      fixes the parked failures) does NOT fail the suite (D-03).

    `[tool.coverage.run]` (D-05 branch coverage on the whole package):
    - `branch = true`
    - `source = ["pc2img"]`
    - `omit = ["*/_version.py"]` — setuptools_scm-generated, not meaningful to cover.

    `[tool.coverage.report]`:
    - `show_missing = true` — term-missing style locally.
    - `exclude_also` list covering the `TYPE_CHECKING` guard, `raise NotImplementedError`,
      and the abstractmethod decorator (values per §2). Do NOT set `fail_under` here — the
      gate lives on the CI command line only (Plan 03).

    CRITICAL — do NOT add `--cov` to `addopts`. A global `--cov` makes every subset run
    (e.g. a single-file run) measure coverage and trip `--cov-fail-under`, and a single
    file reports far below the floor. Coverage flags belong on the CLI/CI invocation only.
  </action>
  <verify>
    <automated>out=$(uv run pytest --collect-only -q 2>&1); noncov=$(printf '%s\n' "$out" | grep -E '^ERROR ' | grep -vE 'test_disk_backed_image_store\.py|test_lazy_disk_cache\.py' | grep -c .); echo "non_d02_error_lines=$noncov"; [ "$noncov" -eq 0 ] && echo COLLECTION_SCOPED_OK</automated>
  </verify>
  <acceptance_criteria>
    - The verify prints `non_d02_error_lines=0` and echoes `COLLECTION_SCOPED_OK` (asserts on grep of the collect output directly — does NOT read `$?` after a pipe). A scoping failure that pulled in the sibling checkouts would surface as non-D-02 ERROR lines and fail this gate.
    - The only remaining `ERROR ` lines are the two D-02 modules (`test_disk_backed_image_store.py`, `test_lazy_disk_cache.py`), which Plan 02 deletes — collect-only does not yet exit 0 at this wave.
    - The parsed `addopts` value is exactly `--import-mode=importlib --strict-markers` and contains no `--cov` substring.
    - `[tool.coverage.run].branch` is `true` and `[tool.coverage.run].source` is `["pc2img"]`.
    - `[tool.coverage.report]` has no `fail_under` key.
